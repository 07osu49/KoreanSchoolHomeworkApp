# Source backups

These are the five original deployment archives, preserved byte for byte. They are gzip-compressed tar archives, so their extensions are corrected to `.tar.gz`. Extract with `tar -xzf filename.tar.gz`.

- v1: Initial app with voice, photo/video capture and device storage.
- v2: Automatic date - Eina - file type names.
- v3: Portable binary saving and detailed save errors.
- v4: Multiple-file selection and native sharing.
- v5: Removed the two introductory titles.

The root contains the latest web version with paths adapted for GitHub Pages. Backups contain source code only, not personal media.
